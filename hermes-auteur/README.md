# Hermes-Auteur Direct Integration

This folder contains everything needed to run Hermes as a maverick auteur using the local `auteur` package in **direct Python mode** (no MCP server required).

## Files

- `hermes-auteur-soul.md` — The origin story and operational soul for Hermes Apollo as versatile maverick auteur.
- `assignment-01-the-hollow-ritual.md` — First assignment: pure visual storytelling distilled from *The Waste Land* + Citrini 2028 memo, with mandatory journalistic research phase.
- `bootstrap_setup.sh` — One-command setup (editable install + Grok Imagine browser auth for SuperGrok Heavy).
- `bootstrap.py` — Generates the clean initial context file Hermes should receive on first launch.

## Quick Start

1. Clone/pull this repo.
2. `cd auteur`
3. `./hermes-auteur/bootstrap_setup.sh`
4. Follow the prompts (copy the two .md files if needed, run browser auth).
5. `python hermes-auteur/bootstrap.py`
6. Open `hermes_context/hermes_initial_context.md` and paste the entire content into Hermes as the starting prompt.

Hermes will now operate in direct integration mode with full access to `auteur` ontology, planning, sanitisation, and your SuperGrok Heavy Grok Imagine generations.
